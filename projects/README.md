# Selected Research & Data Science Projects

This directory collects selected coursework and research projects completed during my studies. Together, the projects cover computational social science, statistical learning, exploratory multivariate analysis, and AI ethics.

> **Portfolio note:** The Master of Data Science dissertation on computational human-value detection remains the primary independent research project in the repository root. The projects below are supplementary evidence of analytical breadth. They are not all independent publications; one is explicitly group coursework.

## Project overview

| Project | Area | Methods / tools | Portfolio value |
|---|---|---|---|
| [Atmospheric Gas Data Analysis](atmospheric-gas-analysis/README.md) | Environmental / statistical data science | R, missing-data diagnostics, MICE, PCA, K-means, hierarchical clustering | Strong supplementary example of a multi-stage statistical workflow |
| [Wine Quality Prediction](wine-quality-prediction/README.md) | Applied machine learning | R, LASSO, Random Forest, cross-validation, feature importance | Supervised-learning example with separate regression and classification tasks |
| [Cancer Risk Assessment](cancer-risk-assessment/README.md) | Applied modelling / health-related data | Python, Random Forest, decision trees; report also discusses logistic and Bayesian models | Group project; predictive results require careful audit |
| [Gender Bias and the Over-Sexualisation of Women in AI](ai-ethics-gender-bias/README.md) | AI ethics / fairness | Literature review and critical argument | Interdisciplinary writing sample, not a coding project |

## Suggested reading order for PhD applications

1. **Master dissertation:** the clearest evidence of independent research design, NLP evaluation, statistical analysis and critical discussion. Start with the repository README and docs/METHODOLOGY.md.
2. **Atmospheric gas analysis:** demonstrates data-quality assessment, missing-data handling, dimensionality reduction and unsupervised analysis.
3. **Wine quality prediction:** demonstrates supervised learning and model evaluation, while also providing an opportunity to discuss metric alignment and class imbalance.
4. **Cancer risk assessment:** demonstrates exposure to multiple modelling paradigms in collaborative coursework. Do not present it as clinical evidence or as sole-authored work.
5. **AI ethics essay:** complements technical projects with an understanding of algorithmic fairness, dataset representation and social impact.

## Authorship and data handling

- The atmospheric analysis, wine-quality analysis and AI ethics essay are presented as individual coursework artefacts based on the supplied materials.
- The cancer-risk report is explicitly identified as Group 28 coursework. The supplied files do not document individual task allocation, so this portfolio does not claim sole authorship of the group report.
- Raw cancer-risk data are not redistributed because the exact source, version and licence were not recorded in the supplied materials, and the file contains a patient identifier field.
- The atmospheric CSV is not redistributed because its upstream source and licence were not established from the supplied archive.
- The wine-quality dataset can be obtained from the UCI Machine Learning Repository. Retain the dataset attribution and follow its CC BY 4.0 terms.

## Portfolio limitations

These are selected academic projects, not peer-reviewed publications or production systems. Reported results are reproduced as stated in their source reports and accompanied by methodological cautions. The original analyses have not all been independently rerun end-to-end as part of this documentation update.
